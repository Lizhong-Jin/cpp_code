# C++ Learning / C++ 学习仓库

## 中文

这是一个个人 C++ 学习仓库，用于记录学习过程中的代码练习、实验与探索，通过实践加深对 C++ 的理解。

本仓库随学习进度持续更新。

统一使用 C++20 标准，需要支持 C++20 的编译器和 CMake 3.31 或更新版本。

## English

This is a personal C++ learning repository for coding exercises, experiments, and exploration. Its goal is to deepen understanding of C++ through hands-on practice.

The repository will continue to evolve as learning progresses.

The repository uses C++20 throughout and requires a C++20-capable compiler and CMake 3.31 or later.
